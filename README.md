# Meesho Interactive Prototype

**Live prototype:** https://messhoprototype.netlify.app/

This project is an interactive Meesho concept prototype created for our DICE challenge submission.

The prototype explores how Meesho can make product discovery and purchase decisions easier through:

- persona-led and mission-first discovery
- regional and festive personalisation
- Meesho Mall for brand and provenance trust
- MTrusted for seller and listing confidence
- proof-first product detail pages
- seller credibility, review intelligence and verified buyer content
- complete-the-look, similar styles and Share & Save journeys

The experience is built around five different user personas and connects the homepage, category pages, trust surfaces, product pages and purchase flow into one clickable journey.

The UI is recreated from scratch in HTML, CSS and JavaScript using our Meesho design concepts and presentation mockups as visual references.
